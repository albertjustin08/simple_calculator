# simple_calculator

A minimal, easy-to-understand calculator project that implements basic arithmetic operations. This repository is intentionally small and readable so you can learn from or extend it quickly.

## Features

- Addition, subtraction, multiplication, division
- Small, clear codebase suitable for learning or quick reuse
- Easy to extend with new operations or interfaces

(Adjust these examples to match the project's actual interface.)

- Add: `add 2 3` → `5`
- Subtract: `sub 5 2` → `3`
- Multiply: `mul 4 3` → `12`
- Divide: `div 10 2` → `5`
